# MusicDL 音乐下载器 · 使用说明

一个文件，双击即用。**对方电脑不需要装任何东西**（无需 Python / Go / Docker）。

- 程序文件：`MusicDL.exe`（约 21 MB，已内嵌全部依赖）
- 支持系统：Windows 64 位
- 需要联网才能下载

---

## 一、最简单的用法：双击

双击 `MusicDL.exe`，会弹出一个黑色命令行窗口，同时自动打开浏览器。

浏览器里是一个音乐搜索与下载页面：

1. 搜索框里输入歌名，比如 `周杰伦 晴天`
2. 点搜索，下方会出现匹配结果
3. 点歌曲右边的下载按钮即可

**下载的文件去哪了？**

就在 `MusicDL.exe` 同级的 `downloads` 文件夹里。窗口上也会打印出完整路径。

首次运行后，同级目录会多出这几个东西，都属正常：

| 文件/目录 | 用途 |
|---|---|
| `downloads\` | **下载的音乐都在这里** |
| `music-dl.exe` | 内部组件（自动释放，不用管） |
| `data\settings.db` | 配置与下载记录 |
| `music-dl.log` | 运行日志，出问题时看这个 |
| `switch-cache-*.json` | 歌单批量下载的换源缓存（加速重跑） |

**用完直接关掉黑色窗口就行。** 若此时还有歌在下载，程序会先把队列跑完再退出，不会留下半截的坏文件。

## 二、批量下整张歌单（推荐）

在 `MusicDL.exe` 所在目录按住 **Shift + 鼠标右键** → 选「在此处打开 PowerShell 窗口」（或「打开命令窗口」），然后：

```powershell
# 方式 A：直接给歌单 ID
.\MusicDL.exe 8691023

# 方式 B：给酷狗歌单链接
.\MusicDL.exe "https://www.kugou.com/yy/special/single/8691023.html"

# 方式 C：指定下载到别处
.\MusicDL.exe 8691023 "D:\我的音乐"
```

窗口会实时打印进度：

```
歌单 ID: 8691023
  解析到 106 首（页面声明 106 首）
共 106 首，开始换源...

  [  1/106] 半兽人                      -> migu   (score 0.44)
  [  2/106] 花海 (KTV版伴奏)              -> migu   (score 0.47)
  [  3/106] 青花瓷 (Live)               -> migu   (score 1.00)
...
提交下载队列: 106 首（换源 106 + 原源回退 0）...
轮询下载状态...
  活跃任务 97 | 全局统计 {'success': 3, 'waiting': 97}
```

**中途关窗口不会丢进度。** 每换源成功一首就写一次缓存，下次重跑同一歌单会自动跳过已完成的换源，直接进入下载阶段。

## 三、下载的音质如何

实测下载结果（逐字节解析音频文件头验证，不是看扩展名）：

| 类型 | 参数 |
|---|---|
| **FLAC 无损** | 44.1 kHz / 16-bit 或 24-bit，立体声（部分曲目为 48 kHz 母带级） |
| **MP3** | 320 kbps / 44.1 kHz（LAME 编码） |

绝大多数曲目能拿到 FLAC 无损。

## 四、常见问题

**Q：搜不到歌 / 歌单解析为空？**
平台接口有频率限制，短时间请求过多会触发。此时等待 2~5 分钟再试。程序本身已内置 10 秒退避重试。

**Q：某些歌显示「换源无匹配，回退原源（需 Cookie）」？**
程序有**双通道换源**：主通道用换源接口，失败后自动走搜索接口按「歌名 + 歌手」精确筛选兜底。
两条通道都找不到才会回退到原始酷狗源 —— **如果填了酷狗 Cookie 就能下到原音质**，没填则这几句会失败。

> 实测（酷狗歌单 8691023，共 106 首）：主通道命中 102 首，兜底通道救回 4 首
> （七里香、稻香、Mojito、不该 Live），最终换源成功率 106/106。

**Q：怎么填酷狗 Cookie（下到原音质）？**
1. 浏览器登录 `www.kugou.com`
2. 按 F12 打开开发者工具 → Network 面板 → 刷新页面
3. 随便点一个 `/api/` 开头的请求 → 复制 Request Headers 里整段的 `Cookie` 值
4. 双击运行 `MusicDL.exe` → 网页里进「设置」页 → 粘贴 Cookie → 保存

> 说明：没有 Cookie 时，部分歌（如周杰伦的《七里香》《稻香》《Mojito》）在酷狗是
> VIP 权限位（`privilege=10`），匿名直取会返回 `Failed to get URL`。换源到 migu
> 可免登录拿到，只是音质降级为 ZQ/MP3。

**Q：下载的歌名和我想的不一样？**
程序会校验换源后的歌名是否与原歌一致（剥离 Live/Remix/伴奏 等版本后缀后比较），不一致的直接拒绝，避免下载到错歌。所以不会出现「下着下着变成别的歌」。

**Q：双击后没有反应 / 窗口一闪而过？**
说明启动失败。右键 → 属性 → 兼容性，勾选「以管理员身份运行」试试；或改用命令行方式运行看报错信息。

**Q：端口被占用？**
程序会自动从 18200 开始找一个空闲端口，无需手动处理。

**Q：能同时开多个吗？**
不建议。同一目录下的实例会互相清理进程（PID 文件机制），这是有意设计——避免残留进程占端口。
